# Math (LaTeX) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add streaming-aware support for inline math (`$..$`, `\(..\)`) and display math (`$$..$$`, `\[..\]`) in `@cacheplane/partial-markdown`. Math content is captured as opaque text — no LaTeX parsing.

**Architecture:** Two new AST kinds (`math-inline` inline, `math-display` block) mirroring the `inline-code`/`code-block` split. Streaming character accumulation per the existing fenced-code pattern. Pandoc-plus adjacency rules on `$`. Per-family disable via parser options.

**Tech Stack:** TypeScript, Vitest. Zero runtime deps maintained.

**Spec:** `docs/specs/2026-05-07-math-design.md`

```ts
// SPDX-License-Identifier: MIT
import type { InternalState } from '../types';

export interface MathOptions {
  dollar: boolean;
  bracket: boolean;
}

export type MathOpenerKind = '$' | '$$' | '\\(' | '\\[';

/**
 * Check whether position `i` in `s` is a valid math opener under the given
 * options. Returns the opener kind or null.
 *
 * Rules summary (from spec):
 *   $$  — block opener if at start-of-line; inline if mid-line.
 *   $   — inline opener iff:
 *           prev char is start/whitespace/punct (not letter/digit);
 *           next char is not whitespace and not ASCII digit (currency guard).
 *   \(  — inline opener iff prev backslash is not itself escaped.
 *   \[  — block opener if at start-of-line; otherwise inline opener.
 *           Same backslash-escape rule.
 */
export function isMathOpenerAt(
  s: string,
  i: number,
  opts: MathOptions,
): { kind: MathOpenerKind } | null {
  const ch = s[i];
  if (!ch) return null;

  // Backslash family.
  if (ch === '\\' && opts.bracket) {
    // Reject if preceded by an unescaped backslash.
    let backslashes = 0;
    for (let j = i - 1; j >= 0 && s[j] === '\\'; j--) backslashes++;
    if (backslashes % 2 === 1) return null;

    if (s[i + 1] === '(') return { kind: '\\(' };
    if (s[i + 1] === '[') return { kind: '\\[' };
    return null;
  }

  // Dollar family.
  if (ch === '$' && opts.dollar) {
    // Backslash-escape: \$ never opens.
    let backslashes = 0;
    for (let j = i - 1; j >= 0 && s[j] === '\\'; j--) backslashes++;
    if (backslashes % 2 === 1) return null;

    // $$ ?
    if (s[i + 1] === '$') return { kind: '$$' };

    // $ inline. Adjacency rules.
    const prev = i > 0 ? s[i - 1] : '';
    const next = s[i + 1] ?? '';
    if (prev && /[\w]/.test(prev)) return null;       // rule #1: not letter/digit before
    if (!next || /\s/.test(next)) return null;        // rule #2: not whitespace after
    if (/[0-9]/.test(next)) return null;              // rule #2b: not digit after
    return { kind: '$' };
  }

  return null;
}

/**
 * Find the closing index for the given opener within `s`, starting from `from`.
 * Returns the byte index of the start of the closer, or -1 if not found.
 */
export function findMathCloser(
  s: string,
  from: number,
  opener: MathOpenerKind,
): number {
  for (let i = from; i < s.length; i++) {
    const ch = s[i];

    if (opener === '$') {
      if (ch === '$') {
        // Backslash-escape check.
        let backslashes = 0;
        for (let j = i - 1; j >= from && s[j] === '\\'; j--) backslashes++;
        if (backslashes % 2 === 1) continue;

        // Rule #3: prev char not whitespace.
        const prev = s[i - 1] ?? '';
        if (/\s/.test(prev)) continue;
        // Rule #4: next char not digit.
        const next = s[i + 1] ?? '';
        if (next && /[0-9]/.test(next)) continue;

        return i;
      }
    } else if (opener === '$$') {
      if (ch === '$' && s[i + 1] === '$') return i;
    } else if (opener === '\\(') {
      if (ch === '\\' && s[i + 1] === ')') {
        // Backslash-escape check on the closer's own backslash.
        let backslashes = 0;
        for (let j = i - 1; j >= from && s[j] === '\\'; j--) backslashes++;
        if (backslashes % 2 === 1) continue;
        return i;
      }
    } else if (opener === '\\[') {
      if (ch === '\\' && s[i + 1] === ']') {
        let backslashes = 0;
        for (let j = i - 1; j >= from && s[j] === '\\'; j--) backslashes++;
        if (backslashes % 2 === 1) continue;
        return i;
      }
    }
  }
  return -1;
}

/** Length of an opener token in characters. */
export function openerLength(kind: MathOpenerKind): number {
  return kind === '$' ? 1 : 2;
}

/** Length of the matching closer token in characters. */
export function closerLength(kind: MathOpenerKind): number {
  return kind === '$' ? 1 : 2;
}
```

```ts
function advanceMathInline(state: InternalState, chunk: string): InternalState {
  if (state.mathNodeId == null || state.mathOpener == null) return state;
  const opener = state.mathOpener as '$' | '\\(';
  const closerIdx = findMathCloser(chunk, 0, opener);
  const node = state.nodes[state.mathNodeId];
  if (!node || node.kind !== 'math-inline') return state;

  if (closerIdx === -1) {
    // Append entire chunk to text; remain in math-inline mode.
    const updated = { ...node, text: node.text + chunk };
    return replaceNode(state, state.mathNodeId, updated);
  }

  // Close at closerIdx.
  const finalText = node.text + chunk.slice(0, closerIdx);
  const updated = { ...node, text: finalText, status: 'complete' as const };
  let s = replaceNode(state, state.mathNodeId, updated);
  const consumed = closerIdx + closerLength(opener);
  s = { ...s, mode: 'inline', mathOpener: null, mathNodeId: null };

  // Recurse with the remaining tail of the chunk in inline mode.
  const tail = chunk.slice(consumed);
  if (tail.length > 0) return pushInternal(s, tail);
  return s;
}
```

function advanceMathDisplay(state: InternalState, line: string): InternalState {
  if (state.mathNodeId == null || state.mathOpener == null) return state;
  const opener = state.mathOpener as '$$' | '\\[';
  const closerIdx = findMathCloser(line, 0, opener);
  const node = state.nodes[state.mathNodeId];
  if (!node || node.kind !== 'math-display') return state;

  if (closerIdx === -1) {
    const updated = { ...node, text: node.text + line + '\n' };
    return replaceNode(state, state.mathNodeId, updated);
  }

  const finalText = node.text + line.slice(0, closerIdx);
  const updated = { ...node, text: finalText, status: 'complete' as const };
  let s = replaceNode(state, state.mathNodeId, updated);
  return { ...s, mode: 'block', mathOpener: null, mathNodeId: null };
}
```

> Note: line-level vs char-level — block-level math operates on lines, not chunks. Verify integration with existing `lineBuffer` machinery: `pushInternal` already buffers per-line for block mode; `advanceMathDisplay` is called once per line.

### Math (LaTeX)

Inline math: `$..$` (Pandoc-style) and `\(..\)` (TeX-style).
Display math: `$$..$$` and `\[..\]`.

```md
Solve $x^2 = 4$ for x to get $$x = \pm 2$$.
GPT-style works too: \(a^2\) and \[\frac{a}{b}\].
```

Math content is captured as an opaque `text: string` — no LaTeX parsing.
Hand the text to KaTeX or MathJax in your renderer.

The `$..$` family follows Pandoc-style adjacency rules with a currency-suppressing
extension: opener `$` must not be followed by whitespace OR an ASCII digit, so
`$5`, `$1.50`, and `It costs $10.` stay as plain text.

#### Parser options

```ts
createPartialMarkdownParser({
  math: { dollar: true, bracket: true },  // both default true
});
```

Disable a family if your input contains a lot of literal `$` (currency-heavy
text) or bare `\(...\)` parenthetical TeX-like syntax that should NOT be math.
```
