# HTML (Inline + Block) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add streaming-aware support for raw HTML in `@cacheplane/partial-markdown`, both inline (`<span>`, `<br>`, comments) and block (`<div>`, `<pre>`, `<script>`). HTML is captured as opaque `raw: string`; sanitization is the consumer's responsibility.

**Architecture:** CommonMark §4.6 / §6.6 detection. Two new AST kinds (`html-block`, `html-inline`). Block has 7 start conditions; inline has 6 patterns. Inline uses a tentative-match buffer (mirrors `tablePending`) for chunk-boundary tolerance.

**Tech Stack:** TypeScript, Vitest. Zero runtime deps maintained.

**Spec:** `docs/specs/2026-05-07-html-design.md`

// SPDX-License-Identifier: MIT
//
// CommonMark §4.6 (HTML blocks) and §6.6 (inline HTML) detection.
// Detection only — state mutations live in block.ts and inline.ts.

/**
 * The fixed list of kind-6 block-level tags from CommonMark §4.6.
 * Source: https://spec.commonmark.org/0.31.2/#html-block
 */
export const HTML_BLOCK_KIND_6_TAGS: readonly string[] = [
  'address', 'article', 'aside', 'base', 'basefont', 'blockquote', 'body',
  'caption', 'center', 'col', 'colgroup', 'dd', 'details', 'dialog', 'dir',
  'div', 'dl', 'dt', 'fieldset', 'figcaption', 'figure', 'footer', 'form',
  'frame', 'frameset', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'head', 'header',
  'hr', 'html', 'iframe', 'legend', 'li', 'link', 'main', 'menu', 'menuitem',
  'nav', 'noframes', 'ol', 'optgroup', 'option', 'p', 'param', 'search',
  'section', 'summary', 'table', 'tbody', 'td', 'tfoot', 'th', 'thead',
  'title', 'tr', 'track', 'ul',
];

const KIND_1_TAGS = ['script', 'pre', 'style', 'textarea'];

const TAG_NAME_RE = /^[A-Za-z][A-Za-z0-9-]*/;
const ATTR_NAME_RE = /^[A-Za-z_:][A-Za-z0-9_.:-]*/;

export type HtmlBlockKind = 1 | 2 | 3 | 4 | 5 | 6 | 7;

/**
 * Return the matching block kind (1..7) or null if `line` does not open a
 * block. Honors leading 0-3 spaces.
 */
export function detectHtmlBlockStart(line: string): HtmlBlockKind | null {
  const stripped = line.replace(/^ {0,3}/, '');

  // Kind 1
  for (const tag of KIND_1_TAGS) {
    const re = new RegExp(`^<${tag}(?:[\\s>]|$)`, 'i');
    if (re.test(stripped)) return 1;
  }

  // Kind 2
  if (stripped.startsWith('<!--')) return 2;

  // Kind 3
  if (stripped.startsWith('<?')) return 3;

  // Kind 4
  if (/^<![A-Za-z]/.test(stripped)) return 4;

  // Kind 5
  if (stripped.startsWith('<![CDATA[')) return 5;

  // Kind 6
  const k6 = /^<\/?([A-Za-z][A-Za-z0-9-]*)\b/.exec(stripped);
  if (k6) {
    const name = k6[1]!.toLowerCase();
    if (HTML_BLOCK_KIND_6_TAGS.includes(name)) {
      const after = stripped[k6[0].length];
      if (after === undefined || after === '>' || after === '/' ||
          after === ' ' || after === '\t') {
        return 6;
      }
    }
  }

  // Kind 7: a complete open or close tag occupying entire line modulo whitespace.
  const trimmed = stripped.trim();
  if (isCompleteTag(trimmed)) return 7;

  return null;
}

function isCompleteTag(s: string): boolean {
  // Open tag
  let m = /^<[A-Za-z][A-Za-z0-9-]*(?:\s+[A-Za-z_:][A-Za-z0-9_.:-]*(?:\s*=\s*(?:"[^"]*"|'[^']*'|[^\s'"=<>`]+))?)*\s*\/?>$/.exec(s);
  if (m) return true;
  // Close tag
  m = /^<\/[A-Za-z][A-Za-z0-9-]*\s*>$/.exec(s);
  return !!m;
}

/**
 * Return true if `line` ends the open block of kind `k`. `opener` is the
 * verbatim content of the opener line (used for kind-1 matching tag name).
 */
export function detectHtmlBlockEnd(
  line: string,
  k: HtmlBlockKind,
  opener: string,
): boolean {
  if (k === 6 || k === 7) return /^\s*$/.test(line);
  if (k === 2) return line.includes('-->');
  if (k === 3) return line.includes('?>');
  if (k === 4) return line.includes('>');
  if (k === 5) return line.includes(']]>');
  if (k === 1) {
    // Match against any of the four kind-1 close tags. The opener-tag name
    // does not strictly matter for CommonMark — any of the four closes any
    // kind-1 block. But we still scope by which one opened.
    for (const tag of KIND_1_TAGS) {
      const re = new RegExp(`</${tag}\\s*>`, 'i');
      if (re.test(line)) return true;
    }
    return false;
  }
  return false;
}

/**
 * Try to match an inline-HTML pattern starting at `i` in `s`.
 * Returns `{ length }` on success, `null` if `s[i]` is not the start of any
 * pattern, or `'pending'` if `s[i]` could begin a pattern but the full
 * match is not yet complete (chunk boundary).
 */
export function matchInlineHtml(
  s: string,
  i: number,
): { length: number } | 'pending' | null {
  if (s[i] !== '<') return null;

  // CDATA, declaration, PI, comment — all start with `<!` or `<?`.
  if (s.startsWith('<!--', i)) {
    const end = s.indexOf('-->', i + 4);
    if (end === -1) return 'pending';
    return { length: end + 3 - i };
  }
  if (s.startsWith('<![CDATA[', i)) {
    const end = s.indexOf(']]>', i + 9);
    if (end === -1) return 'pending';
    return { length: end + 3 - i };
  }
  if (s[i + 1] === '!' && /[A-Za-z]/.test(s[i + 2] ?? '')) {
    const end = s.indexOf('>', i + 2);
    if (end === -1) return 'pending';
    return { length: end + 1 - i };
  }
  if (s[i + 1] === '?') {
    const end = s.indexOf('?>', i + 2);
    if (end === -1) return 'pending';
    return { length: end + 2 - i };
  }

  // Open or close tag
  const closing = s[i + 1] === '/';
  const start = i + (closing ? 2 : 1);
  const nameMatch = TAG_NAME_RE.exec(s.slice(start));
  if (!nameMatch) {
    // `<` not followed by a tag name → not HTML.
    return null;
  }
  let j = start + nameMatch[0].length;

  if (closing) {
    while (j < s.length && /\s/.test(s[j]!)) j++;
    if (j >= s.length) return 'pending';
    if (s[j] !== '>') return null;
    return { length: j + 1 - i };
  }

  // Open tag: optional attributes, optional /, then >
  while (j < s.length) {
    const ch = s[j]!;
    if (ch === '>') return { length: j + 1 - i };
    if (ch === '/' && s[j + 1] === '>') return { length: j + 2 - i };
    if (/\s/.test(ch)) {
      // Maybe attribute
      while (j < s.length && /\s/.test(s[j]!)) j++;
      if (j >= s.length) return 'pending';
      if (s[j] === '>' || (s[j] === '/' && s[j + 1] === '>')) continue;
      const attrName = ATTR_NAME_RE.exec(s.slice(j));
      if (!attrName) return null;
      j += attrName[0].length;
      // Optional value
      while (j < s.length && /\s/.test(s[j]!)) j++;
      if (s[j] === '=') {
        j++;
        while (j < s.length && /\s/.test(s[j]!)) j++;
        if (j >= s.length) return 'pending';
        if (s[j] === '"') {
          const end = s.indexOf('"', j + 1);
          if (end === -1) return 'pending';
          j = end + 1;
        } else if (s[j] === "'") {
          const end = s.indexOf("'", j + 1);
          if (end === -1) return 'pending';
          j = end + 1;
        } else {
          // Unquoted
          while (j < s.length && !/[\s'"=<>`]/.test(s[j]!)) j++;
        }
      }
    } else {
      return null;
    }
  }
  return 'pending';
}
```

function isOpenParagraph(state: InternalState): boolean {
  const top = state.stack[state.stack.length - 1];
  if (top == null) return false;
  const node = state.nodes[top];
  return !!node && node.kind === 'paragraph' && node.status !== 'complete';
}

function openHtmlBlock(
  state: InternalState,
  line: string,
  kind: 1 | 2 | 3 | 4 | 5 | 6 | 7,
): InternalState {
  const [s1, nodeId] = allocId(state);

  // Check single-line close (e.g., `<!-- foo -->` on one line).
  const closesNow = detectHtmlBlockEnd(line, kind, line);
  const node: HtmlBlockAstNode = {
    id: nodeId,
    kind: 'html-block',
    parentId: state.rootId!,
    status: closesNow ? 'complete' : 'streaming',
    raw: line,
    htmlKind: kind,
  };
  let s2 = appendNode(s1, node);
  s2 = appendChild(s2, state.rootId!, nodeId);
  if (closesNow) {
    return { ...s2, mode: 'block' };
  }
  return {
    ...s2,
    mode: 'html-block',
    htmlBlockKind: kind,
    htmlBlockNodeId: nodeId,
  };
}

import { detectHtmlBlockEnd } from './handlers/html';

function advanceHtmlBlock(state: InternalState, line: string): InternalState {
  if (state.htmlBlockKind == null || state.htmlBlockNodeId == null) return state;
  const node = state.nodes[state.htmlBlockNodeId];
  if (!node || node.kind !== 'html-block') return state;

  const isEnd = detectHtmlBlockEnd(line, state.htmlBlockKind, node.raw);

  // Append line to raw (kinds 6/7 do NOT include the terminating blank line).
  const newRaw =
    (state.htmlBlockKind === 6 || state.htmlBlockKind === 7) && isEnd
      ? node.raw
      : node.raw + '\n' + line;
  const updated = {
    ...node,
    raw: newRaw,
    status: isEnd ? 'complete' : 'streaming',
  } as const;
  let s = replaceNode(state, state.htmlBlockNodeId, updated);
  if (isEnd) {
    s = { ...s, mode: 'block', htmlBlockKind: null, htmlBlockNodeId: null };
  }
  return s;
}
```

    // Hold remainder (with cap) in htmlInlinePending; exit the inline scanner
    // so next push can re-attempt.
    const HOLD_CAP = 4096;
    if (remainder.length > HOLD_CAP) {
      // Buffer overflow — flush as plain text.
      // Fall through to plain-text accumulation.
    } else {
      return {
        ...s,
        htmlInlinePending: remainder,
        // Caller exits the inline scanner — handled by return to push loop.
      };
    }
  } else if (result !== null) {
    // Match found.
    const raw = remainder.slice(0, result.length);
    const [s1, nodeId] = allocId(s);
    const node: HtmlInlineAstNode = {
      id: nodeId,
      kind: 'html-inline',
      parentId,
      status: 'complete',
      raw,
    };
    let s2 = appendNode(s1, node);
    s2 = appendChild(s2, parentId, nodeId);
    index += result.length;
    s = s2;
    continue;
  }
  // result === null: not HTML — fall through to plain-text path; '<' becomes
  // a literal character in the text node.
}
```

> **Note on pending buffer:** For the simple case of "exit inline scanner and re-enter on next push," the existing `lineBuffer` handling already concatenates pending content. The `htmlInlinePending` field is for a case where the `<` is in a paragraph mid-stream and we need to remember NOT to flush the prior text yet. Implementation may simplify to: when `pending` returns, push the bytes back into `lineBuffer` so they re-enter the scanner on the next push. Confirm during integration.

```markdown
### HTML

Raw HTML — both inline tags (`<span>`, `<sub>`, `<br>`) and block-level
constructs (`<div>`, `<details>`, `<script>`) — is captured as opaque
pass-through nodes carrying the literal source text.

```md
<details>
<summary>Click to expand</summary>
Hidden content with **markdown** disabled inside HTML blocks.
</details>

A formula H<sub>2</sub>O renders inline.
```

The parser implements [CommonMark §4.6 (HTML blocks)](https://spec.commonmark.org/0.31.2/#html-blocks)
and [§6.6 (raw HTML inline)](https://spec.commonmark.org/0.31.2/#raw-html).
Each HTML block carries `kind: 1..7` for the seven CommonMark start
conditions; inline nodes carry `raw` only.

#### Security — sanitize before rendering

`raw` is unsanitized HTML source. Rendering directly via
`dangerouslySetInnerHTML` is an XSS risk. Sanitize first:

```ts
import DOMPurify from 'dompurify';

if (node.type === 'html-block' || node.type === 'html-inline') {
  return <div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(node.raw) }} />;
}
```

For untrusted streaming output, prefer rendering HTML nodes as escaped text
unless you can ensure sanitization at every render.
```
